FAQ

Common questions

No jargon, straight answers.

Will merging delete data I want to keep?
+

No. You always choose which record is the "primary" — the one that survives. You can also export a CSV backup before anything is deleted, so you always have a safety net. We show you a full preview of exactly what will be merged before you confirm.

Does it work with custom Salesforce objects?
+

Yes. Merge Engine works with any Salesforce object — standard objects like Contact, Lead, and Account, as well as any custom objects you've created. Standard objects use the native Salesforce merge API. Other objects use a smart re-parent-and-delete method.

What happens to related records when I merge?
+

All related records (Opportunities, Cases, Activities, custom child records) are automatically moved to the primary record before deletion. Nothing is orphaned or lost.

Is my data sent to any external server?
+

Absolutely not. Merge Engine is 100% native Salesforce — it runs entirely inside your Salesforce org using Apex code. No data is ever sent to external servers.

How long does it take to set up?
+

About 5 minutes. Install the managed package from AppExchange, assign the necessary permissions, and you're ready to start merging. No code, no configuration files, no consultants required.

What if I accidentally merge the wrong records?
+

We strongly recommend using the CSV export before every merge session — this creates a backup you can reference. Once records are merged in Salesforce, they cannot be automatically undone. However, with your CSV backup, your admin can manually restore records if needed.
