Precision Merging

Field Value Cherry-Picking

Don't settle for "all or nothing" merges. Merge Engine allows you to select a surviving primary record, while seamlessly bringing over specific field values from secondary records.

  • ✓
    Surviving Primary: Choose the best master record with one click.
  • ✓
    Secondary Overrides: Selectively pull better phone numbers, emails, or custom fields from duplicates.
  • ✓
    Visual Feedback: Instantly see which values will survive in the final merged record.
AI Search

Intelligent AI Fuzzy Matching

Our proprietary AI doesn't just look for exact matches. It understands context, typos, and token shuffling to find duplicates you never knew existed.

  • ✓
    Jaro-Winkler Algorithm: Catches misspellings and transposed letters automatically.
  • ✓
    Token Overlap: Knows that "Microsoft Corporation" and "Corporation Microsoft" are the same entity.
  • ✓
    Confidence Scoring: Automatically groups duplicates into High (≥90%), Medium, and Low confidence tiers.
Advanced Queries

Powerful SOQL Filter Builder

Need to target a specific subset of records? Build complex queries without writing a single line of code, complete with live SOQL previews.

  • ✓
    Email Domain Matching: Instantly group records that share the same company domain (e.g., @company.com).
  • ✓
    Public Domain Exclusion: Automatically exclude common free providers like @gmail.com or @yahoo.com from domain matches.
  • ✓
    Exact Duplicates: Find records sharing exact values across text, ID, or picklist fields.
Enterprise Security

Role-Based Access Control

Maintain strict governance over who can view, merge, and export your Salesforce data with built-in permission tiers.

  • ✓
    Merge Engine Admin: Full access to configure settings, execute merges, and export CSV backups.
  • ✓
    Merge Engine User: Can search and merge records securely, but restricted from exporting data.
  • ✓
    Read-Only Access: Perfect for analysts. View duplicate groups and data health without the ability to delete.
Data Integrity

Intelligent Child Re-Parenting

Never orphan a record again. Merge Engine automatically scans all related objects and ensures child records move to the surviving primary record.

  • ✓
    Cross-Object Support: Works across both Standard objects and Custom objects seamlessly.
  • ✓
    Master-Detail & Lookups: Handles tightly coupled (Master-Detail) and loosely coupled (Lookup) relationships safely.
  • ✓
    Bulk Sequential Merging: Merges multiple groups automatically while maintaining Salesforce database locks and integrity.
